UniAccounts
About the Project
UniAccounts is a Java-based university account management system.
This project demonstrates the implementation of software design patterns in Java.
Technologies
Java
Object-Oriented Programming (OOP)
IntelliJ IDEA
Project Structure
app: Main application.
audit: Audit logging.
model: Student account model.
observer: Observer design pattern.
repository: Student repository.
state: State design pattern.
strategy: Export strategies.
Design Patterns
Singleton
Builder
Observer
State
Strategy
Export Features
JSON Export
CSV Export
How to Run
Clone this repository.
Open the project in IntelliJ IDEA.
Configure the Java JDK.
Run Main.java.
